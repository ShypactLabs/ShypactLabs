# Shypact Labs

Shypact Labs is an independent software group building Android apps and browser prototypes for communication, learning and productivity.

## Work with Shypact Labs

[Prepare an Android project brief](https://shypact.com/android-development). Describe the app, choose the features you need and tell us how to reach you.

## Try the projects

- **[Shywish web demo](https://shypact.com/shywish/#demo)** — Explore a sample profile, send a simulated request and see how a chat opens after approval. Shywish for Android is in development.
- **[Browser Lab](https://shypact.com/#lab)** — Try quick notes, multiplication, a JavaScript exercise, English vocabulary and a focus timer.
- **[Project notes](https://shypact.com/project-notes)** — See what is available now, how the website works and what is being explored.
